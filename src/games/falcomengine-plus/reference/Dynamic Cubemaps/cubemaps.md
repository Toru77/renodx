This page documents the Dynamic Cubemaps system, which provides real-time environment mapping by capturing the scene into cubemaps that are then used for realistic reflections on surfaces. The system generates both standard environment cubemaps for general PBR materials and specialized reflection cubemaps for water surfaces.

For information about Screen Space Global Illumination, see [4.2](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/4.2) For water rendering details, see [5.2](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/5.2) For image-based lighting and skylighting, see [4.4](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/4.4)

* * *

## System Overview

The Dynamic Cubemaps feature implements a three-stage compute shader pipeline that progressively builds high-quality environment maps from screen-space data. The system captures the surrounding environment each frame, infers missing data, and generates pre-filtered specular irradiance maps for physically-based rendering.

### Key Capabilities

- **Real-time environment capture** from screen-space depth and color buffers [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl9-10](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl#L9-L10)
- **Temporal accumulation** to build complete 360-degree cubemaps over multiple frames [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl101-108](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl#L101-L108)
- **GGX importance sampling** for physically-accurate specular pre-filtering [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/SpecularIrradianceCS.hlsl46-56](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/SpecularIrradianceCS.hlsl#L46-L56)
- **Dual cubemap paths** supporting both standard reflections and water-specific reflections [src/Features/DynamicCubemaps.h73-83](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/src/Features/DynamicCubemaps.h#L73-L83)
- **Screen Space Reflections (SSR)** integration for water surfaces [src/Features/DynamicCubemaps.cpp23-25](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/src/Features/DynamicCubemaps.cpp#L23-L25)

### Cubemap Face Direction Calculation

The shader reconstructs the 3D direction vector for each cubemap texel based on the face index and UV coordinates in `GetSamplingVector` [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl17-50](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl#L17-L50):

```
// From UpdateCubemapCS.hlsl:29-48
switch (ThreadID.z) {
    case 0: result = float3(1.0, uv.y, -uv.x); break;
    case 1: result = float3(-1.0, uv.y, uv.x); break;
    case 2: result = float3(uv.x, 1.0, -uv.y); break;
    case 3: result = float3(uv.x, -1.0, uv.y); break;
    case 4: result = float3(uv.x, uv.y, 1.0);  break;
    case 5: result = float3(-uv.x, uv.y, -1.0); break;
}
```

### Temporal Accumulation Strategy

The system uses temporal accumulation with a fixed lerp factor of 0.5 to progressively build the cubemap [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl101-108](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl#L101-L108):

- **New samples** are blended with existing data at 50% weight.
- **Old samples** fade based on distance from camera using `smoothbumpstep(0.0, 2.0, distance)` [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl120-132](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl#L120-L132)
- **Position tracking** stores world positions scaled by 0.001 [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl98](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl#L98-L98)
- **Camera movement** is compensated by adjusting stored positions with `CameraPreviousPosAdjust2` [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl115](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/UpdateCubemapCS.hlsl#L115-L115)

## Stage 2: Cubemap Inference

The inference stage fills gaps in the captured cubemap by sampling from progressively lower mip levels and blending with a default fallback cubemap.

### Missing Data Handling

The inference shader implements a hierarchical gap-filling strategy [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/InferCubemapCS.hlsl61-90](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/InferCubemapCS.hlsl#L61-L90):

1. **Mip levels 0-7**: Sample progressively blurred versions of the captured cubemap.
2. **Mip level 8**: If still incomplete, average the centers of all 6 cubemap faces [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/InferCubemapCS.hlsl68-73](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/InferCubemapCS.hlsl#L68-L73)
3. **Brightness scaling** (non-reflections only): Apply exponential brightness boost `k^mipLevel` where `k = 1.5` [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/InferCubemapCS.hlsl57-58](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/InferCubemapCS.hlsl#L57-L58)
4. **Blending**: Lerp with static default cubemap or reflection texture based on `mipLevel / 7.0` [features/Dynamic Cubemaps/Shaders/DynamicCubemaps/InferCubemapCS.hlsl92-96](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/features/Dynamic%20Cubemaps/Shaders/DynamicCubemaps/InferCubemapCS.hlsl#L92-L96)

## Shading Integration and SSR

The dynamic cubemaps are sampled during the deferred composition pass or within forward lighting shaders for specular contributions.

### Screen Space Reflections (SSR) Integration

For water surfaces, the system integrates a ray-marched Screen Space Reflection pass.

```
Application [ISApplyReflections.hlsl]

Raytracing [ISReflectionsRayTracing.hlsl]

main() raymarch

Binary Search refinement

SSRParams (b2)

main() apply

WaterMaskTex (t1)

SSRSourceTex (t0)
```

- **Raymarching**: `ISReflectionsRayTracing.hlsl` performs 64 iterations of linear marching followed by binary search refinement to find intersections in screen space [package/Shaders/ISReflectionsRayTracing.hlsl30-82](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/package/Shaders/ISReflectionsRayTracing.hlsl#L30-L82)
- **Fading**: Reflections fade based on ray length, screen edges, and depth thickness [package/Shaders/ISReflectionsRayTracing.hlsl85-95](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/package/Shaders/ISReflectionsRayTracing.hlsl#L85-L95)
- **Reprojection**: Temporal stability is achieved by reprojecting alpha from the previous frame using motion vectors [package/Shaders/ISReflectionsRayTracing.hlsl108-118](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/package/Shaders/ISReflectionsRayTracing.hlsl#L108-L118)
- **Composition**: `ISApplyReflections.hlsl` blends the SSR results with the main buffer, masked by the water surface detection [package/Shaders/ISApplyReflections.hlsl31-41](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/package/Shaders/ISApplyReflections.hlsl#L31-L41)

## Rendering Pipeline Integration

### Cell Change Reset

The system resets the capture state when entering a new cell by listening for `RE::LoadingMenu` events via the `MenuOpenCloseEventHandler` [src/Features/DynamicCubemaps.cpp146-157](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/src/Features/DynamicCubemaps.cpp#L146-L157)

### Cubemap Creator

A specialized "Creator" mode allows exporting a 1x1 cubemap from a selected color and roughness for debugging or static material creation. It uses `device->CreateTexture2D` and `DirectX::CaptureTexture` to generate and save the resulting `.dds` to `Data\textures\DynamicCubemaps` [src/Features/DynamicCubemaps.cpp42-115](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/src/Features/DynamicCubemaps.cpp#L42-L115)

### BC6H Compression

The system compresses the final filtered cubemaps to `BC6H` format using a compute shader `bc6hEncodeCS` to reduce GPU memory bandwidth during sampling [src/Features/DynamicCubemaps.h107-117](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/src/Features/DynamicCubemaps.h#L107-L117) This is performed as the final stage of the cubemap update cycle [src/Features/DynamicCubemaps.h98-101](https://github.com/doodlum/skyrim-community-shaders/blob/7ae9bdd6/src/Features/DynamicCubemaps.h#L98-L101)
