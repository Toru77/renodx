<h1>CORTAO lookup table generators</h1>

This folder contains scripts and code for generating lookup tables. Note that pregenerated lookup tables available [here](../../tables).

<h2>Occluder lookup table generators</h2>

At the moment only a Python script is available. This script can be run as-is to generate a set of common lookup tables. The generation can be be customized at the end of the file.

A C port of the Python script in the form of a .h file is planned, which can be used to generate the lookup table texture data live instead of loading data from disk.
